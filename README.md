# Quiz Game

A Python-based Quiz Game that allows users to test their knowledge through multiple categories and difficulty levels.

## Features

- Multiple quiz categories:
  - Python
  - Programming
  - Computer
  - Math
- Difficulty selection:
  - Easy
  - Medium
  - Hard
- Randomized question order
- Randomized answer options
- Answer validation
- Skip question option
- Score tracking
- Correct and wrong answer count
- Questions attempted count
- Unanswered questions count
- Percentage calculation
- Best score tracking
- Replay option
- Multiple quiz attempts

## Technologies

- Python
- Random module
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- Exception handling
- List comprehension
